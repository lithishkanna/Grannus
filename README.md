# Grannus

 Grannus is a multilingual, voice-first rural healthcare communication platform designed to bridge the communication gap between rural patients and urban doctors in India.

## Core Flow

Patient Voice
↓
Audio Preprocessing
↓
Sarvam Speech-to-Text
↓
Medical Information Extraction
↓
Safety / Red-Flag Screening
↓
Feature Extraction
↓
Random Forest Priority Classification
↓
Doctor Review

## Features

- Indian-language voice input
- Background noise reduction
- Sarvam AI speech-to-text
- Medical information extraction
- Safety and red-flag detection
- Follow-up question generation
- Random Forest priority classification
- Explainable priority results
- Doctor-oriented structured output
- Multilingual translation
- Text-to-speech support
